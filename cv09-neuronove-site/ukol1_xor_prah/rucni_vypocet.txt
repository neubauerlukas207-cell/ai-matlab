RUCNI VYPOCET - Neuronova sit pro XOR s prahovou aktivacni funkci

Architektura site:
  - Skryty neuron:   vahy [0.3, 0.3], prah 0.5
  - Vystupni neuron: vahy [0.3, 0.3, -0.6], prah 0.2

Prahova aktivacni funkce:
  step(s) = 1  pokud s >= 0
  step(s) = 0  pokud s <  0
  kde s = (vazeny soucet vstupu) - prah


--- Kombinace 1: x1=0, x2=0 ---
  Skryty neuron:
    s_h = 0*0.3 + 0*0.3 = 0.0
    s_h - prah = 0.0 - 0.5 = -0.5
    h = step(-0.5) = 0

  Vystupni neuron:
    s_o = 0*0.3 + 0*0.3 + 0*(-0.6) = 0.0
    s_o - prah = 0.0 - 0.2 = -0.2
    y = step(-0.2) = 0

  Ocekavano XOR(0,0) = 0 --> SPRAVNE


--- Kombinace 2: x1=0, x2=1 ---
  Skryty neuron:
    s_h = 0*0.3 + 1*0.3 = 0.3
    s_h - prah = 0.3 - 0.5 = -0.2
    h = step(-0.2) = 0

  Vystupni neuron:
    s_o = 0*0.3 + 1*0.3 + 0*(-0.6) = 0.3
    s_o - prah = 0.3 - 0.2 = 0.1
    y = step(0.1) = 1

  Ocekavano XOR(0,1) = 1 --> SPRAVNE


--- Kombinace 3: x1=1, x2=0 ---
  Skryty neuron:
    s_h = 1*0.3 + 0*0.3 = 0.3
    s_h - prah = 0.3 - 0.5 = -0.2
    h = step(-0.2) = 0

  Vystupni neuron:
    s_o = 1*0.3 + 0*0.3 + 0*(-0.6) = 0.3
    s_o - prah = 0.3 - 0.2 = 0.1
    y = step(0.1) = 1

  Ocekavano XOR(1,0) = 1 --> SPRAVNE


--- Kombinace 4: x1=1, x2=1 ---
  Skryty neuron:
    s_h = 1*0.3 + 1*0.3 = 0.6
    s_h - prah = 0.6 - 0.5 = 0.1
    h = step(0.1) = 1

  Vystupni neuron:
    s_o = 1*0.3 + 1*0.3 + 1*(-0.6) = 0.3 + 0.3 - 0.6 = 0.0
    s_o - prah = 0.0 - 0.2 = -0.2
    y = step(-0.2) = 0

  Ocekavano XOR(1,1) = 0 --> SPRAVNE
