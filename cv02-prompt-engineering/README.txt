README – Uloha 4 (Prompt Engineering)

Cilem teto ulohy bylo pomoci LLM vygenerovat MATLAB funkci,
ktera provadi rozklad celeho cisla na prvocinitele.

Obsah slozky:
- muj_prompt.txt
  Vlastni prompt, ktery jsem pouzil pro generovani kodu.

- prime_factors.m
  MATLAB funkce, ktera provadi rozklad cisla na prvocinitele.

- test_prime_factors.m
  Testovaci skript, ktery overuje spravnost funkce.

- LLM_Audit.txt
  Strucny popis prace s LLM, testovani a vlastniho hodnoceni.

Postup kontroly:
1) Otevrit MATLAB
2) Nastavit tuto slozku jako pracovni
3) Spustit prikaz: test_prime_factors
4) Pokud se vypise "VSE OK", je reseni spravne

Reseni bylo otestovano v MATLABu.
