Napis MATLAB funkci prime_factors(N), ktera vrati rozklad na prvocinitele.

FORMAT:

- Vystup factors je radkovy vektor (1xn) serazeny vzestupne

1) Pokud N je prvocislo -> factors = [N]
2) Pokud N <= 1 nebo N neni cele -> factors = [] (a vypis varovani)
3) Pokud N = 0 nebo zaporne -> factors = [] (a vypis varovani)
4) Funkce nesmi padat ani pro divne vstupy (NaN, Inf, vektor) -> jen vrat [] a varovani
